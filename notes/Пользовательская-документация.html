Суть

Страница User Documentation — это полный индекс пользовательской документации Samba Wiki. Она собирает в одном месте ссылки на FAQ, руководства по установке и миграции, статьи по диагностике, практические руководства (HowTos), man-страницы, категории вики и рекомендуемые книги. Служит отправной точкой для администраторов, ищущих документацию по развёртыванию и эксплуатации Samba.
