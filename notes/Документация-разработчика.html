Developer Documentation (Документация для разработчиков)

Суть

Страница «Developer Documentation» Samba Wiki — полный каталог ссылок на документацию для разработчиков Samba. Это не руководство с инструкциями, а оглавление: разделы ведут к страницам о участии в разработке, планировании релизов, исходном коде, тестировании и отладке, сообщении об ошибках, безопасности, VFS-модулях, кластеризации, сборке и историческим материалам. Страница последний раз редактировалась 4 ноября 2025 года.

Samba codebase organization (организация кодовой базы)

Дерево исходников делится на пять основных групп:

  • Top-level libraries — общий код, разделяемый процессами Samba;
  • Source3 — код, используемый главным образом файл-сервером и членом домена;
  • Source4 — код, используемый главным образом контроллером домена Active Directory;
  • Infrastructure components — сборка и тестовый каркас Samba;
  • Autogenerated code — автогенерируемый код (разбор пакетов DCE/RPC и других регулярно структурированных буферов).

Подводные камни

  • GitHub — не канонический репозиторий. Со страницы: «Samba is no longer actively developed on GitHub but for reference and to keep old code from being mistakenly examined, the Offical Samba Team GitHub Mirror is kept up to date» — активная разработка ведётся в Git на git.samba.org, а зеркало на GitHub поддерживается лишь для справки, чтобы не изучать устаревший код.
  • Документация по VFS разделена по версиям Samba: «The new version of Writing a Samba VFS» относится к Samba 3.6 и более ранним, а для Samba 4.0 и выше предназначена страница «Writing a Samba VFS Module» — не перепутайте их.
  • Раздел Security неполон: ссылка «Samba Protocol Security Layers» — красная (страница в вики пока не создана).
