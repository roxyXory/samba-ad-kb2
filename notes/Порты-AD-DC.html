База знаний Samba AD DC

Использование портов Samba AD DC

Суть

Страница описывает, какие порты должен открывать Samba-контроллер домена Active Directory (AD DC) и как посмотреть, на каких портах и интерфейсах он реально слушает. Служба samba, обеспечивающая функции AD DC, требует, чтобы на контроллере домена были открыты порты DNS, Kerberos, LDAP/SMB, NetBIOS и динамические RPC-порты. Список нужен прежде всего для настройки межсетевого экрана между DC и остальной сетью.

Ключевое

Как посмотреть прослушиваемые порты и интерфейсы

Чтобы определить порты и сетевые интерфейсы, на которых слушает Samba AD DC, выполните (команда дословно со страницы):

# netstat -plaunt | egrep "ntp|bind|named|samba|?mbd"

В примере вывода на странице службы слушают на localhost (127.0.0.1) и на сетевом интерфейсе с адресом 10.99.0.1; при этом на обоих интерфейсах открыты порты 139/tcp, 88/tcp и 445/tcp. Подробности по выводу — в man-странице netstat(8). Чтобы привязать Samba к конкретным интерфейсам, на странице дана ссылка на статью «Configure Samba to Bind to Specific Interfaces».

Порты, которые должны быть открыты на DC

Служба samba, предоставляющая функции AD DC, требует открытия на контроллере домена следующих портов (таблица дословно из источника):

Служба Порт Протокол
DNS * 53 tcp/udp
Kerberos 88 tcp/udp
ntp ** 123 udp
End Point Mapper (DCE/RPC Locator Service) 135 tcp
NetBIOS Name Service 137 udp
NetBIOS Datagram 138 udp
NetBIOS Session 139 tcp
LDAP 389 tcp/udp
SMB over TCP 445 tcp
Kerberos kpasswd 464 tcp/udp
LDAPS *** 636 tcp
Global Catalog 3268 tcp
Global Catalog SSL *** 3269 tcp
Dynamic RPC Ports **** 49152-65535 tcp

Сноски к таблице (дословно по смыслу источника):

  • * — DNS может обеспечиваться внутренним DNS-сервером Samba либо DNS-сервером Bind9.
  • ** — если на DC настроен и запущен ntp.
  • *** — если в файле smb.conf установлено tls enabled = yes (значение по умолчанию).
  • **** — диапазон совпадает с диапазоном портов, используемым Windows Server 2008 и новее. Samba версий до 4.7 вместо этого использовала TCP-порты с 1024 по 1300. Чтобы вручную задать диапазон портов в Samba 4.7 и новее, установите параметр rpc server port в файле smb.conf; подробности — в описании параметра в man-странице smb.conf(5).

Подводные камни

  • Со страницы (предупреждение в рамке): в зависимости от вашей установки службы, отличные от samba, могут открывать дополнительные порты, необходимые для вашего окружения AD.
  • Порт 53 требуется открывать, только если DNS-бэкендом на DC служит внутренний DNS-сервер Samba или Bind9.
  • Порт 123/udp нужен, только если на DC настроен и работает ntp.
  • Порты 636 (LDAPS) и 3269 (Global Catalog SSL) открыты лишь при tls enabled = yes в smb.conf (по умолчанию включено).
  • Диапазон динамических RPC-портов 49152-65535 соответствует Windows Server 2008+; Samba до версии 4.7 использовала TCP-порты 1024-1300 — при настройке файрвола для старых версий диапазон другой.
