Суть

Главная страница Samba Wiki — входная точка официальной документации проекта Samba: набора свободного ПО с открытым исходным кодом, который с 1992 года предоставляет файловые и печатные службы для всех разновидностей SMB/CIFS-клиентов, включая многочисленные версии Microsoft Windows. Samba распространяется свободно по GNU General Public License, а сам проект входит в Software Freedom Conservancy. Для темы AD DC страница ценна сводным списком ключевых руководств пользователя: развёртывание контроллера домена, ввод члена домена, присоединение DC к существующему AD, обновление Samba и настройка ресурсов.
