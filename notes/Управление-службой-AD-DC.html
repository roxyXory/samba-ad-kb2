Управление службой Samba AD DC

Суть

Страница «Managing the Samba AD DC Service» — обзорная точка входа по управлению службой контроллера домена Samba; она сводит три способа: через systemd, через init-скрипт и через Upstart (каждому посвящена отдельная страница вики). Ключевой факт повседневной эксплуатации: на DC служба /usr/local/samba/sbin/samba сама запускает требуемые службы smbd и winbindd как подпроцессы, поэтому отдельно их запускать нельзя. Поставляемого unit-файла systemd у Samba нет — при сборке DC из исходников его создают вручную, после чего службой управляют стандартными systemctl enable/disable/start/stop.

Ключевое

Служба samba на контроллере домена

  • На DC служба /usr/local/samba/sbin/samba автоматически запускает необходимые smbd и winbindd как подпроцессы (страница Using Systemd, раздел «The samba Service»).
  • Если пакетный поставщик создал дополнительные файлы служб Samba, их нужно отключить и замаскировать, чтобы другие службы не смогли снова их включить:
# systemctl mask smbd nmbd winbind
# systemctl disable smbd nmbd winbind

Управление через systemd (основной способ для современных ОС)

  1. Samba не поставляет unit-файл systemd. Если контроллер домена собран из исходников, создайте файл /etc/systemd/system/samba-ad-dc.service со следующим содержимым:
[Unit]
Description=Samba Active Directory Domain Controller
After=network.target remote-fs.target nss-lookup.target

[Service]
Type=forking
ExecStart=/usr/local/samba/sbin/samba -D
PIDFile=/usr/local/samba/var/run/samba.pid
ExecReload=/bin/kill -HUP $MAINPID

[Install]
WantedBy=multi-user.target
  1. Перечитайте конфигурацию systemd:
# systemctl daemon-reload
  1. Включить автозапуск службы при загрузке системы:
# systemctl enable samba-ad-dc
  1. Отключить автозапуск:
# systemctl disable samba-ad-dc
  1. Ручной запуск и остановка:
# systemctl start samba-ad-dc
# systemctl stop samba-ad-dc

Все перечисленное предполагает, что служба управляется файлом samba-ad-dc; если unit-файл не создавался вручную, имя службы Samba AD DC нужно смотреть в документации своей ОС. Подробности — на man-странице systemd.service(5).

Управление через init-скрипт (устаревшие ОС)

  • Для ОС, использующих другие системы управления службами (например, systemd), вики отсылает к способу через systemd; на Red Hat Enterprise Linux новее версии 6 используется именно systemd.
  • Скрипт создаётся как /etc/init.d/samba-ad-dc (на странице вики приведены готовые варианты для Red Hat Enterprise Linux 6 и Debian; в Debian при необходимости правят пути к samba, утилите samba-tool и файлу smb.conf внутри скрипта).
  • Сделать скрипт исполняемым:
# chmod 755 /etc/init.d/samba-ad-dc
  • Включение и отключение автозапуска (RHEL 6):
# chkconfig samba-ad-dc enable
# chkconfig samba-ad-dc disable
  • Включение и отключение автозапуска (Debian):
# update-rc.d samba-ad-dc defaults
# update-rc.d -f samba-ad-dc remove
  • Ручной запуск и остановка:
# service start samba-ad-dc
# service stop samba-ad-dc

Способ включения/отключения службы зависит от ОС — сверяйтесь с её документацией.

Управление через Upstart

Загрузить конфиг-файл Upstart:

$ wget -O /etc/init/samba-ad-dc.conf "https://salsa.debian.org/samba-team/samba/raw/jessie/debian/samba-ad-dc.upstart"

Сама процедура вики помечена предупреждением о непроверенном внешнем содержимом (см. «Подводные камни»).

Подводные камни

  • Не запускайте smbd и winbindd на DC вручную. Служба /usr/local/samba/sbin/samba сама запускает их как подпроцессы; при ручном запуске Samba DC не работает, как ожидается.
  • Маскируйте службы от пакетного поставщика (systemctl mask smbd nmbd winbind), а не только отключайте — иначе другие службы смогут снова их включить.
  • Unit-файл systemd не входит в поставку Samba — при сборке из исходников его создаёт администратор. Если вы его не создавали, точное имя службы Samba AD DC смотрите в документации своей ОС.
  • Debian init-скрипт может отказать в старте из-за прав на TLS-ключ (CVE-2013-4475). Скрипт проверяет права на /usr/local/samba/private/tls/key.pem: если они не 600, выводится «wrong permission on ... must be 600» и «samba will not start (CVE-2013-4475)»; удаление всех tls .pem-файлов вызовет их авторегенерацию с корректными правами.
  • Способ для Upstart ссылается на непроверенный внешний контент (предупреждение на странице вики), а его источник — конфиг из ветки jessie репозитория Debian.
